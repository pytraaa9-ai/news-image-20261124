A program that writes one image summing up Tuesday 24 November 2026 world news — a newspaper front page (1024×1024 PNG): lead story the AI rally reverses as a tariff threat hits chips, second story Asia's record AI rally with Taiex up 9%, plus 48 more stories across six continents, a world map, and Tuesday's market close with the Dow's first close above 50,000. Full-day edition, v2 — 50 stories.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
